gsd-agent-wiki

A portable, git-based knowledge base for coding agents. It remembers what you have learned across projects.

View on GitHub Quick start

Why

GSD (Get Shit Done) runs the work and tracks per-project state. gsd-agent-wiki is the long-term memory layer: durable concepts, patterns, lessons, preferences, and decisions, stored as plain Markdown. Agents consult it before big decisions.

GSD remembers where the work is. gsd-agent-wiki remembers what you have learned.

How it works

No server, no SDK

Markdown with YAML frontmatter, following Open Knowledge Format (OKF) v0.2. Read it with any editor or agent.

Reviewed writes only

Candidates are staged in an inbox, then promoted to the wiki on a branch after you approve the diff.

Works without GSD

GSD is a convenient source of input, never a dependency.

Cheap retrieval

Agents read the index, then page descriptions, then search, and open full pages last.

Quick start

git clone https://github.com/wesnam/gsd-agent-wiki
cd gsd-agent-wiki
claude --add-dir /path/to/gsd-agent-wiki

Capture with /kb-capture, review with /kb-curate, check health with /kb-lint. Details in the README.
